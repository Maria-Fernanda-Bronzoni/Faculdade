# Detona Hero

## Sobre o jogo
Detona Hero é um jogo de plataforma inspirado no filme **Detona Ralph**, onde o jogador controla um personagem que precisa consertar janelas quebradas por um vilão que anda pelo prédio. O objetivo é restaurar todas as janelas no menor tempo possível.

O jogo foi desenvolvido usando Python e a biblioteca Pygame, com foco em lógica de movimentação, animações e interatividade simples.

## Recursos visuais
- Todas as imagens (sprites, personagens, efeitos e elementos visuais) foram obtidas no site [CraftPix.net](https://craftpix.net), respeitando os termos da licença de uso.
- A imagem do prédio foi criada por mim (Maria Fernanda Bronzoni), personalizada para este jogo.

## Como o jogo funciona
- O vilão anda pelas janelas do prédio de forma automática, quebrando cada uma com uma animação.
- O jogador controla o herói que deve consertar as janelas quebradas dentro de um tempo limite com as teclas (a w s d) e pressionando a tecla (espaço) para consertar.
- O jogo registra o tempo que o jogador levou para consertar todas as janelas, permitindo comparar resultados no ranking.

## Tecnologias usadas
- Python 3.12.3
- Pygame
