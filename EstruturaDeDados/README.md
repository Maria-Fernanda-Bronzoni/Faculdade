# Estrutura de Dados

Atividades desenvolvidas na disciplina de **Estrutura de Dados**, utilizando **Python**.

## 📚 Conteúdo

### Questão 1 — Tabela Hash

Implementação de uma **Tabela Hash com endereçamento em cadeia**, utilizando listas encadeadas para tratar colisões.

Arquivo:

* `questao1.py`

### Questão 2 — Tabela Hash

Implementação de uma **Tabela Hash aplicada a um sistema de emplacamento de veículos**, utilizando o último número da placa como representação do estado de registro.

Arquivo:

* `questao2.py`

## 🛠️ Tecnologias

* Python
* Estruturas de Dados
* Tabela Hash
* Lista Encadeada

## 🎯 Objetivo

Praticar conceitos fundamentais de estruturas de dados, incluindo **tabelas hash, funções de dispersão, tratamento de colisões e listas encadeadas**.
